# Birla Open Minds × Omyra Technologies

A Next.js App Router presentation with 34 slides, three image-free chapter covers, keyboard and touch navigation, searchable slide overview, full-screen mode and print styles. Only the opening cover uses a photograph. All assets are local.

## Run

```sh
npm ci
npm run dev
```

Open http://localhost:3000/#partnership on this computer.

## Production

```sh
npm run build
npm start
```

## Editing

- `app/page.tsx`: React presentation controls and navigation.
- `app/slides.json`: trusted static slide markup, titles and chapter groups.
- `app/globals.css`: base presentation styling.
- `app/revision.css`: three-chapter layouts, timelines and diagrams.
- `public/assets/`: local font, school visuals and supplied research PDF.

Controls: left/right arrows, Page Up/Page Down or Space; Home/End; F for fullscreen; G for the searchable slide overview. Swipe horizontally on touch devices.

The default server listens on localhost only. The presentation includes the supplied research PDF. Publishing or network sharing is a separate step.
